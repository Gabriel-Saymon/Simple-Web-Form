# 🧠 Quiz Interativo para Programadores

Este projeto foi desenvolvido como uma forma de **revisar e praticar conceitos fundamentais de HTML e CSS**, por meio da criação de um **formulário interativo em formato de quiz**.  
O foco é exercitar a estruturação de páginas web e a aplicação de estilos utilizando apenas **HTML e CSS puros**.

---

## 🚀 Objetivo do Projeto

O objetivo principal é **revisar os fundamentos das linguagens HTML e CSS**, aplicando elementos básicos e intermediários como:
- Estrutura semântica de páginas HTML;
- Criação de formulários com diferentes tipos de inputs;
- Utilização de tabelas, listas e elementos interativos (`<details>`, `<summary>`);
- Estilização de componentes com CSS;
- Organização e hierarquia de seletores;
- Uso de cores, fontes e espaçamentos.

---

## 🧩 Tecnologias Utilizadas

- **HTML5:** para a estrutura e conteúdo da página.  
- **CSS3:** para a estilização visual e responsividade simples.  
- **Google Fonts (Cabin):** para personalização tipográfica.

## 🖥️ Funcionalidades

- Formulário com **diversos tipos de perguntas**:
  - Múltipla escolha (radio)
  - Campo de texto
  - Campo de senha
  - Data
  - Checkbox
  - Upload de arquivo
  - Seleção por menu `<select>`
- **Tabela de pontuação** que mostra diferentes avaliações conforme o desempenho.
- **Gabarito interativo** com o uso de `<details>` e `<summary>`.
- **Formulário de feedback** com campos de nome, email e comentários.
- Mensagem de confirmação ao enviar o feedback (`alert()`).
- Rodapé com créditos e link para o portfólio do desenvolvedor.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram revisados e aplicados:
- Estrutura semântica de um documento HTML5 (`header`, `main`, `section`, `footer`, etc.);
- Atributos de formulários (`type`, `placeholder`, `name`, `id`, `value`, etc.);
- Elementos de acessibilidade como `label` e `legend`;
- Organização de estilos com **Flexbox**;
- Boas práticas de reset de estilos com o uso do seletor universal `*`.
